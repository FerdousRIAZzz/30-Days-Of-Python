## 📁 Structure

Each day gets its own folder:

```
30-Days-Of-Python/
├── day-01-number-guessing-game/
│   ├── main.py
│   └── README.md
├── day-02-calculator/
│   ├── main.py
│   └── README.md
├── ...
└── README.md   <- this file
```

Each day's `README.md` is short — just:
- What it does
- What you practiced / learned
- How to run it

## 🛠️ Tech

Python 3.x, standard library first — external packages (`requests`, `BeautifulSoup`, `Flask`) only from Day 16 onward, as noted in the table.

## 📝 Notes

This repo is a daily practice log, not a portfolio of polished apps — some days will be rough, and that's fine. The stronger projects get cleaned up and featured separately once the 30 days are done.
